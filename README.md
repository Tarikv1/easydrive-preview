# easydrive-preview

Temporary preview of the Fahrschule Easy Drive website at https://easydrive.pagecraftory.com
before the site moves to its real domain. Every page is `noindex,nofollow`, `robots.txt` disallows
crawling and there is no sitemap. Generated from the project's `src/` with
`node scripts/build.mjs --out <dir> --staging-host easydrive.pagecraftory.com`; edit the source, not this copy.
